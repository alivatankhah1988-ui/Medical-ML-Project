# Medical ML Project

A machine learning project focused on diabetes prediction using clinical data.

## Project Overview

This project explores the use of machine learning techniques to predict diabetes outcomes based on clinical and laboratory features.

The project is being developed as a research-oriented machine learning project, with an emphasis on data analysis, model evaluation, interpretability, and reproducibility.

## Dataset

The dataset contains clinical and laboratory measurements related to diabetes.

## Features

- Age
- Gender
- FBS (Fasting Blood Sugar)
- HbA1c
- TG (Triglycerides)
- Cholesterol

## Target

- "Result": Diabetes outcome ("YES" / "NO")

# Machine Learning Models

The following models are being explored:

- Logistic Regression
- Decision Tree

Additional machine learning models and evaluation techniques will be added as the project develops.

## Project Goals

- Explore and clean clinical data
- Analyze important features
- Build baseline machine learning models
- Compare model performance
- Evaluate models using appropriate metrics
- Investigate interpretability
- Address issues such as class imbalance and data leakage
- Improve reproducibility and research quality
